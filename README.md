# Space-X-A-comic-history
Um FPS Retrô, com uma abertura cinematográfica em HQ e gameplay em pixel art.

Uma idéia de jogo que surgiu de dois jovens enquanto tomavam café. Vamos praticar a criação de games usando Construct 3 para proporcionar uma nova experiência de jogo e história.

## Estrutura do repositório

Cada pasta é uma parte do projeto, disponível para conferencia:

- Resumo (One-Sheet)
   - One-Sheet
- Personagens:
   - Crew (Comandante)
   - Elena (Navegadora)
   - Davis (Copiloto)


## Objetivo

Praticar conceito de criação de jogos, obter o Know-How, incluindo:

- Criação de personagens
- Level design
- Storytelling
- Dublagem

## Tecnologias e ferramentas (até o momento)

- Piskel
- Construct 3
- Word (One-Sheet)
