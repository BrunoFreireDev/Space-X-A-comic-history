## Sobre o Projeto

Um FPS Retrô, com uma abertura cinematográfica em HQ e gameplay em pixel art.

Uma ideia de jogo que surgiu de dois jovens enquanto tomavam café. Vamos praticar a criação de games usando Construct 3 para proporcionar uma nova experiência de jogo e história.
